# Washer.E01 Digital Forensics Report

## Objective

The Washer.E01 project aimed to perform a forensic examination of the Washer computer hard drive image. The focus was on identifying deleted or hidden files, verifying file integrity, and uncovering digital evidence of illegal activities. The project provided hands-on experience with forensic tools, log analysis, and documenting findings in a structured manner.

### Skills Learned

- Conducting forensic examinations of disk images.
- Verifying MD5 and SHA1 hashes to ensure evidence integrity.
- Identifying and analyzing suspicious user activity and files.
- Using digital forensic tools to extract, document, and preserve evidence.
- Creating timelines and correlating data across multiple sources for investigation.
